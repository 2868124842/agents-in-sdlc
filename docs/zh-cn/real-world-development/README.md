通过贴近实际的场景、完整应用和共享待办列表，探索 GitHub Copilot 在软件开发生命周期中的应用。您将迭代完成变更规划、代码编写、行为测试、拉取请求评审以及代理任务管理。

## 场景

您是 Tailspin Toys 的新开发人员。这是一家虚构公司，为以开发者为主题的桌游提供众筹服务。团队已将待办工作登记为 GitHub issues，供您选择处理，其中既有筛选和分页等功能，也有无障碍访问和编码标准等质量改进任务。

## 选择工作环境

无论在哪里工作，都可以使用 GitHub Copilot。请选择适合您开发方式的环境。每个工作坊都有自己的设置流程，并采用相同的 Tailspin Toys 场景。

### [GitHub Copilot CLI][cli]

在终端中使用智能体助手，体验 Plan 和 Autopilot 模式、说明文件、技能、自定义代理、Playwright MCP、Agent Merge 和实用斜杠命令。

### [GitHub Copilot 应用][app]

在桌面应用中运行并行代理会话、切换会话模式、协作处理 Canvas，并管理 GitHub issues 和拉取请求。

### [GitHub Copilot 云智能体][cloud]

将 GitHub issues 分配给异步云智能体、引导其工作、监控进度，并评审它创建的拉取请求。

### [Visual Studio Code][vscode]

在 Visual Studio Code 和 GitHub Codespaces 中使用 GitHub Copilot。在不离开编辑器的情况下使用 Copilot Chat 代理模式、MCP 服务器和自定义代理。
